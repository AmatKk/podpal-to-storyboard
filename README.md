# Podpáľ to a choď pešo – storyboard

Storyboard Dacia spotu (4 obrazy, 24 záberov).

**Web:** https://amatkk.github.io/podpal-to-storyboard/

## Ako upravovať
- Otvor `index.html` na GitHube a klikni na ceruzku (Edit), alebo stlač `.` pre editor v prehliadači.
- Texty záberov sú v poli `shots` (dolu v `<script>`): `act` = akcia, `snd` = zvuk, `alt` = náhradná verzia, `size` = veľkosť záberu, `cam` = pohyb kamery.
- Kresby políčok sú funkcie `A['1.1']`, `A['1.2']`… (SVG v rozmere 320×180).
- Po uložení (Commit changes) sa web aktualizuje asi do minúty.
